# monaco editor electron

Standalone app for monaco editor in electron

## Download

Windows: [monaco.exe](https://github.com/leonardobdev/monaco-editor-electron/releases/download/v1.0.0/monaco.exe)

Linux: [monaco.AppImage](https://github.com/leonardobdev/monaco-editor-electron/releases/download/v1.0.0/monaco.AppImage)

## How to build the project

```bash
# Install dependencies
npm install

# build the project
npm run dist
```
