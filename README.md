# monaco editor  electron

Standalone app for monaco editor in electron

## Download

Windows: [monaco-editor-electron.exe](https://github.com/leonardobdev/monaco-editor-electron/raw/main/monaco-editor-electron.exe)

Linux: [monaco-editor-electron.AppImage](https://github.com/leonardobdev/monaco-editor-electron/raw/main/monaco-editor-electron.AppImage)

## How to build the project

```bash
# Install dependencies
npm install

# build the project
npm run dist
```
